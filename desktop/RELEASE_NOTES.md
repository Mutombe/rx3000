The counter sale goes to the till like everything else, and what a sale was
paid with is recorded again.

**Selling over the counter no longer takes the money in the dispensary**

A medicine sold with advice at the dispensary counter used to be paid for
there. It is now raised like any other supply and settled at the till, which is
the last place that still worked the old way.

Nothing else about it changes: the consultation, the counselling and the
customer's name are recorded exactly as before, and the sale appears in
Awaiting payment with the bag's own number on it.

**How a sale was paid is recorded again**

The payment method follows the medicine onto the patient's record, the reports
and the printed documents. It was only ever written for a counter sale settled
in the dispensary, so from the moment payment moved to the till the field was
quietly left empty on everything else. It is written where the money is taken
now, so it is right for every sale.

If you have wondered why a dispensing showed nothing under how it was paid,
that is why. It applies from here on; it does not go back and fill in what was
already missed.

**Still worth knowing, from the version before this one**

If a machine would not start the software at all, with "the code execution
cannot proceed because VCRUNTIME140_1.dll was not found", that is fixed. The
missing piece is built into the program now. Install the current version from
the website and it will start; the automatic update cannot reach a program that
was never able to run.

No money is taken anywhere in the dispensary. A dispensed script waits at the
till, goes out with a driver who collects at the door, or is claimed from a
medical aid with any shortfall waiting at the till.

Where a scheme does not carry the whole bill you are told the moment the script
is dispensed, whether there is a shortfall or not, using what the scheme
actually allowed rather than the estimate. If the patient would rather go
elsewhere, "They have declined it" puts the medicine back, stops the scheme
being billed and takes the loyalty points off, behind a code.

At the till, scan the script's barcode and the bag opens with what is owed
already in it. Or type the script number into the same box the products go in.
Or search Awaiting payment, which now takes a script number, an invoice number
or a name, and searches everything still owed for rather than the newest
twenty. A part payment no longer hides the bag from that list.
