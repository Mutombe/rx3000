Screens now arrive whole, and several of them stop saying things that were not
true.

**A screen no longer loads the parts of itself it already knows**

Opening a screen used to grey out nearly all of it, including the headings, the
labels beside every figure, the column names and the search box. None of that
comes from the server. It is the same on every visit, so it is on screen from
the moment you arrive, and the only things that wait are the spots the figures
land in.

Fifty three screens were measured, one at a time, with the answers held back on
purpose to see what each one drew while it waited. The whole product works this
way now.

**Two screens were telling you the pharmacy had nothing**

Branches and Compounding did not show a loading state at all. They showed their
empty message, so every time you opened them they said "No branches" or "No
formulae yet" until the list happened to arrive. Both were wrong every time.

**Screens that answered before the question had been asked**

Money owed said nobody owed the pharmacy anything. Deliveries said nothing was
out. Drivers said nobody was set up to deliver. Orders said nothing was at or
below its reorder level. Each of those was said before the server had answered,
so a slow morning read as an empty shop. A screen now waits to be told
something before it reports that there is nothing.

**A red box announcing nothing**

The System screen opened on an error box on every visit, with no error in it.

**Dates with nothing recorded**

Every date in the software went through three pieces of shared code, and all
three printed a dash where there was no date. A dash makes "never happened",
"not applicable" and "we could not read it" look identical, and on a printed
report it reads as a redaction. They say so in words now, and a column can say
what its own absence means: a collection date that never came reads "Not
collected", not a general phrase.

**A patient's prescriptions**

Each script drew its own separate table, so the columns down a patient's record
never lined up with each other. It is one table now, with one set of column
headings, and each script banded across it.

**The screen you sign in on no longer opens on a message about a token**

A till left overnight came back in the morning with "Invalid or expired token"
written across the card where you sign in. Nobody asked it anything about a
token. What
had happened is that the session ran out, which is ordinary, and it says so:
"Your session has ended. Please sign in again."
